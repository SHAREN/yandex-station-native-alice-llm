# Исправление пропуска начала речи при Native Streaming TTS (2026-11-04)

## Симптомы

На Яндекс Станции Lite 1 после включения нового режима версии 0.4.5e пользователем наблюдались обрывы фраз: анекдот о провалах памяти озвучивался не полностью; по запросу «посчитай до 30 вслух» начало (числа 1–9) не было слышно, речь начиналась с десяти.

## Доказательства из реального устройства (не предположения)

- 2026-11-04 14:55:17 UTC: в `maind.log.1` получены все три части анекдота — «Доктор, у меня провалы в памяти», «И давно?», «Что давно?». Аудиоплеер начал воспроизведение после передачи текста.
- 2026-11-04 14:59:02 UTC: `maind` получил первый текстовый фрагмент «Один, два, три, четыре, пять, шесть, семь, восемь, девять», затем оставшуюся часть; озвучка стартовала только после отправки второй части.
- **Контролируемый сетевой тест реального Yandex UniProxy:** `TtsGenerate(IsStreaming=true, Text="Один...девять")` + `DeferredTtsGenerate(Text="Десять...пятнадцать",IsLast=true)` вернул 44 749 байт аудио. Вариант с `TtsGenerate(Text="")` и тем же deferred-куском вернул **точно такие же байты и такой же SHA-256**. Вариант, где обе части отправлены через два `DeferredTtsGenerate`, вернул 91 394 байта аудио. Заключение: **при IsStreaming=true сервер игнорирует Text исходного TtsGenerate**.
- Значит, первая фраза была потеряна именно на уровне протокольного использования TTS, а не потому, что GPT не выдал текст, и не из-за кнопок звука.

## Исправленная архитектура 0.4.5f

1. **Только одна нативная TTS-сессия на ответ.** Отправить `TtsGenerate{Text:"",IsStreaming:true}` (обычное событие 13) для открытия потока.
2. **Весь речевой текст, начиная с первого слова**, передавать последовательными `DeferredTtsGenerate` (событие 34), прикреплёнными к ID начального запроса. Каждое сообщение содержит `Text`, следующий `ChunkNum`, `IsLast=false`.
3. **Отсутствует сегментация по точке/запятой, логика «первая/вторая/третья фраза», таймер прогностической предварительной озвучки и отдельные TtsGenerate.** Транспорт может объединять короткие GPT-дельты (на границах пробелов) для сокращения пакетов, **но это не деление на отдельные синтезы**: всё принадлежит одной сессии и отправляется до окончания полного текста.
4. На завершении GPT отправить `DeferredTtsGenerate{Text:"",IsLast:true}`. Пустой финальный текст подтверждён тестом на реальном UniProxy.
5. **Аудио:** оригинальный поток Ogg/Opus и оригинальный streamId отправляются непосредственно в штатный плеер Lite 1. Старый `oggSpeech` (пересборка нескольких независимых Ogg-сегментов, задержанные EOS/StreamControl) в режиме native streaming **не используется**. Один `TtsSpeak`, один Ogg-поток, один финальный `StreamControl.Close`.
6. Прежняя логика сохранена в коде исключительно за отключением feature flag; её не удаляли, но при наличии `/data/opt/quasar-bridge/enable-native-streaming-tts` она не вызывается для потоковых LLM-ответов.

## Проверки

- `go test ./... -count=1 -timeout=120s`: все пакеты прошли.
- Целевые интеграционные тесты повторялись 20–25 раз.
- `TestNativeTTSOneSessionIncrementalBeforeLLMCompletes`: самый первый текст отправлен как `DeferredTtsGenerate` **до завершения GPT**; исходный `TtsGenerate.Text` пуст; итоговый текст совпадает побайтово с потоком GPT; один TTS-ID.
- `TestNativeTTSCountingAllNumbersWithoutSentenceSplits`: весь счёт от «Один» до «тридцать» передан точно и полностью без пунктуационного разделения на запросы.
- `TestNativeStreamingForwardsOriginalAudioUnchanged`: Ogg payload отправлен напрямую побайтово идентично; ровно один `TtsSpeak` и один `StreamControl.Close`.

## Производство и откат

- Новая собранная версия **0.4.5f**, ELF Linux/ARM64, SHA256 `2a45c6cffc7e4469bd4b1d68f597c2f9dafa759f707763e8dae9de681b634206`.
- Установлена на Lite 1 на место пользовательского `quasar-bridge` с SHA-защитой и автоматическим откатом, команда установки вернула `DEPLOY_OK`, PID при запуске `6535`; `/healthz` = `status:ok`. Стоковая файловая система остаётся только для чтения. Флаг native streaming включён.
- Старая 0.4.5e сохранена на устройстве как `/tmp/quasar-bridge-0.4.5e-rollback` SHA256 `cbe8a72f0ba77385308c1e0922c289e5654961759f44a8b26250c61c3a338067` (пока нет перезапуска: /tmp временный). Предыдущая версия 0.4.5d сохранена локально в другом историческом каталоге. Инструмент установки `_tmp/deploy-native-stream-fix-20261104.sh`.
- После установки был проверен бинарник, здоровье процесса и статус флага. **Физическая прослушка после 0.4.5f ещё не выполнена.** Соединение maind↔Bridge после рестарта нужно проверить на входящем голосовом запросе; нулевые счётчики сразу после перезапуска сами по себе не являются доказательством отсутствия соединения.
