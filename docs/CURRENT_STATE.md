# Состояние проекта — 2026-11-04

## Канонический проект

Этот отдельный репозиторий — исходная точка для дальнейшей разработки **штатной Алисы с нашей нейросетью**. Старый GitHub проект Gemini Live не является местом для следующих изменений native TTS.

## Подтверждено тестами

- UniProxy принимает один TtsGenerate с IsStreaming=true, последующие DeferredTtsGenerate (включая пустой IsLast), возвращает Opus до финального текста, использует один streamId.
- Полные Go-тесты Quasar Bridge и интеграционные тесты нового протокола прошли, проверена маршрутизация «Тише» к Яндексу и длинной истории к LLM.

## Ещё требуется

- Физический голосовой тест «Яндекс, расскажи мне длинную интересную историю»: первая фраза должна начинаться до окончания генерации, текст не должен повторяться или обрываться.
- Проверить субъективную непрерывность интонации, остановку голосом, перебивание, завершение и переподключение после cold boot.
- Если есть сбой, сначала собрать только диагностику времени/размеров; затем выключить feature flag и использовать сохранённый fallback.
- Анализ случая «счёт до 30 начинается с десяти», контрольный эксперимент и исправление: [NATIVE_TTS_STREAMING_BUGFIX](NATIVE_TTS_STREAMING_BUGFIX_20261104.md). Для 0.4.5f физическая прослушка всё ещё нужна; сразу после перезапуска сервиса `healthz=ok`, но без нового голосового запроса WS-счётчики могут оставаться нулевыми.
