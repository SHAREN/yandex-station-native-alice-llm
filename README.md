# Yandex Station — Native Alice + Custom LLM

**Отдельный проект для Яндекс Станции Lite 1:** штатная Алиса с другой нейросетью, без замены прошивки, микрофонов, распознавания речи или голоса.

Это **адаптация Quasar Bridge** с собственными дополнениями для родного протокола Алисы, GPT-релея и потокового синтеза текста. Мы не разрабатываем новую прошивку; мы изменяем маршрут обработки запроса на границе UniProxy и возвращаем ответ через штатную озвучку Яндекса.

## Как это работает

```text
«Яндекс, расскажи длинную историю»
       │
       ▼
Штатная Lite 1: активация, микрофоны, VQE/AEC, ASR
       │
       ▼
Quasar Bridge (на колонке, перехват UniProxy/AAPI)
       ├── Штатные команды ──► облачная Алиса (музыка, таймеры, громкость)
       └── Вопрос/история ──► GPT-релей / нейросеть
                                   │ поток готового текста
                                   ▼
                           TtsGenerate(IsStreaming=true)
                           DeferredTtsGenerate(ChunkNum=1…n)
                                   │
                                   ▼
                    Яндекс UniProxy TTS → единый Opus-поток
                                   │
                                   ▼
                        Штатный проигрыватель Lite 1
```

Первые готовые фразы отправляются в TTS до завершения всего ответа. Следующие порции продолжают **одну** нативную сессию синтеза. Разделение текста по логическим знакам препинания используется как точка отправки, а не как создание новых независимых голосовых запросов.

Интернет для штатного ASR и озвучки Яндекса по-прежнему нужен.

## Состав репозитория

- `src/quasar-bridge/` — модифицированный Quasar Bridge на Go: маршрутизация, штатный AAPI, нативный streaming TTS, аудиопоток, тесты.
- `src/quasar-llm-relay/` — релей текстовой модели на Home PC, без Gemini Live.
- `tools/` — сборка Go для Linux/ARM64 и безопасный статический аудит TTS-протокола.
- `docs/` — архитектура, активное состояние, доказательства потокового TTS и откат.

**Не входит:** код, сервер, двусторонний аудиоканал и эксперименты проекта Gemini Live. Они остаются в отдельном репозитории `SHAREN/yandex-station-gemini-bridge`.

## Проверка

```bash
cd src/quasar-bridge
go test ./... -count=1
```

Сборка Linux/ARM64 на Home PC через Windows Go (запуск из корня проекта):

```bash
bash tools/go-cross-build.sh src/quasar-bridge _tmp/quasar-bridge-native-arm64 ./cmd/quasar-bridge
```

`_tmp/` — локальные артефакты, никогда не отправляются в GitHub.

Рабочая версия на физической Lite 1 — **`sentence-tts-20261105`** (коммит [`ae4ff5a`](https://github.com/SHAREN/yandex-station-native-alice-llm/commit/ae4ff5af5db3d246fbdc22625e46ee3790af27e4)). Ранние сборки 0.4.5e/0.4.5f — история и варианты отката, **не текущая рабочая версия**.

Поиск Brave/Tavily и прямой Home Assistant на 07.11 подготовлены, но **не включены в production**.
